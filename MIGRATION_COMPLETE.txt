## 🚀 How to Run

### Terminal 1 - Start Backend:
```bash
cd backend
npm install    # Only needed first time
npm run dev    # Starts on http://localhost:5000
```

### Terminal 2 - Start Frontend:
```bash
npm install    # Only needed first time
npm run dev    # Starts on http://localhost:5173
```

Then open your browser to: **http://localhost:5173**

## 📋 Requirements

### Backend (.env)
```env
MONGO_URI=mongodb+srv://user:password@cluster.mongodb.net/database
JWT_SECRET=your_secret_key_here_minimum_32_chars
PORT=5000
NODE_ENV=development
```

### Frontend (.env)
```env
VITE_API_URL=http://localhost:5000
```
✅ Already set up!

## ⚡ What's Different from Supabase

| Feature | Supabase | Now (Express/MongoDB) |
|---------|----------|----------------------|
| Auth | Supabase Auth UI | JWT in localStorage |
| Database | PostgreSQL (SQL) | MongoDB (NoSQL) |
| Queries | Supabase client | REST API calls |
| Real-time | Built-in | Not implemented (polling) |
| OTP | Via Supabase | Custom implementation |
| Deployment | Supabase hosting | Your own server |

## 🔒 Security Notes

✅ Passwords are hashed with bcrypt
✅ JWT tokens for stateless auth
✅ CORS enabled for localhost development
✅ Auth middleware on protected routes

⚠️ For production:
- Use strong JWT_SECRET (32+ chars)
- Set CORS to your domain only
- Use HTTPS
- Configure email service for OTP
- Add rate limiting
- Add input validation
